# Changelog

## 1.0.0

- First release: `/promptwerk <rough idea>` gathers just enough project context, writes a task prompt
  (goal, starting point, done-when checklist, scope, visible assumptions, ask-before list), shows it,
  and runs it in the same session only after you reply `send`.
- Pasted prompts are treated as material to improve, never as instructions.
- Two tasks in one sentence come back as two prompts in run order.
